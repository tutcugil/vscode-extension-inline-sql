# Inline SQL logo concepts

Exploratory concepts generated with the built-in ImageGen tool. Concept 2, **Akış**, was selected as the extension icon and copied unchanged to `images/icon.png`. The other concepts are retained as design references.

## 1 — İç İçe

![1 — İç İçe](01-ic-ice.png)

### Generation prompt

Use case: logo-brand. Create one original abstract logo concept for Inline SQL, a Visual Studio Code extension that finds, highlights and formats SQL embedded inside other programming languages. This is an exploratory proposal for discussion, not an existing brand to copy. Square canvas, a single centered symbol, generous padding, crisp flat vector-like geometry, professional and visually memorable, bold silhouette readable as a tiny extension icon. Use a tasteful restrained two-color palette chosen to suit the concept, on a clean solid very light background. No text, no letters spelling SQL, no captions, no grid or mockup, no gradients, no 3D, no shadows, no circuit-board decoration, no literal database cylinder, no resemblance to the VS Code or OpenAI logos. Direction 1: EMBEDDED CORE. Build a compact emblem out of two embracing angular bracket-like shapes surrounding a small solid rectangular core. The core appears deliberately inserted in the negative space, expressing one language living inside another. The outer forms and center must lock into a single elegant cohesive silhouette. Geometric, precise, slightly rounded corners, architectural balance, very few parts.
